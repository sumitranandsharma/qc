Capstone Project Overview

Hybrid Classical-Quantum Machine Learning for Pulmonary Diagnosis

This educational research prototype evaluates the integration of Deep Classical Computer Vision with Quantum Machine Learning (QML) for chest radiograph classification (Normal vs. Pneumonia). Under current Noisy Intermediate-Scale Quantum (NISQ) limits, loading raw 50,000+ pixel images onto quantum circuits is physically intractable. We implement a hybrid architecture: a pre-trained ResNet-18 extracts deep spatial features, Principal Component Analysis (PCA) reduces the latent vector into an orthogonal 4-qubit budget, and a PennyLane Variational Quantum Classifier (VQC) executes parameterized unitary classification on a statevector simulator.

Why Hybrid Architecture?

Directly loading high-resolution ($224 \times 224 = 50,176$ pixels) scans into quantum circuits exceeds current NISQ qubit budgets. ResNet-18 acts as an inductive bias filter, extracting spatial textures before PCA compresses variance into a manageable 4-qubit Hilbert space.

Variational Quantum Ansatz

The VQC employs parameterized single-qubit rotations ($R_y, R_z$) paired with circular CNOT entangling ladders. Optimization via the analytical Parameter-Shift Rule ensures exact quantum gradients without numerical finite-difference approximation errors.

Unbiased Scientific Control

To prevent biased comparisons, classical baselines (SVM RBF, Linear SVM, Logistic Regression, MLP) are evaluated on the identical PCA-compressed features. This isolates the decision boundary engine and rigorously benchmarks quantum classification capability.

State Preparation & Encoding

            

              Features $x_i \in [0, \pi]$ are encoded using Angle Embedding:
              $|\psi(x)\rangle = \bigotimes_{i=0}^{3} R_y(x_i) |0\rangle$.
              This rotates the state on the Bloch sphere along the Y-axis without requiring excessive circuit depth.
            

          

          

            
Gradient Optimization via Parameter-Shift

            

              Trained on simulator using analytical gradients:
              $\frac{\partial \langle Z \rangle}{\partial \theta} = \frac{1}{2} [\langle Z(\theta + \frac{\pi}{2})\rangle - \langle Z(\theta - \frac{\pi}{2})\rangle]$.
              This allows exact backpropagation into the classical Adam optimizer.

Genuine Capstone Analysis: Classical vs Quantum Performance

        

          The 4-qubit Variational Quantum Classifier achieves an impressive 83.3% test accuracy and 82.0% F1-score on the held-out medical test set, matching the classical RBF Support Vector Machine (83.3%). Classical linear models (Logistic Regression & Linear SVM) achieve 87.9%, benefiting from the linearly separable representation already learned by ResNet-18 in the top principal axes. In accordance with genuine research standards, we do not claim quantum supremacy in this NISQ simulator regime; rather, we demonstrate that hybrid parameterized quantum circuits successfully learn clinically meaningful decision boundaries with only 18 trainable quantum parameters.

          Viva Voce Defense Questions & Technical Answers
        

        
        

          

            
Q1: Why was PCA necessary before passing features to the quantum model?

            

              Answer: ResNet-18 outputs a 512-dimensional continuous feature vector. In current NISQ simulators and quantum hardware, encoding 512 features directly via angle embedding would require 512 qubits. Amplitude embedding would require $\log_2(512) = 9$ qubits, but preparing arbitrary amplitude states requires exponential gate depth ($\mathcal{O}(2^9)$ CNOTs), leading to extreme decoherence and barren plateaus. PCA mathematically compresses the 512 features along the orthogonal axes of highest variance, allowing 4 qubits to capture the dominant spatial variation while preserving circuit shallow depth.
            

          


          

            
Q2: Why did you choose Angle Embedding over Amplitude Embedding?

            

              Answer: Angle embedding operates with constant circuit depth $\mathcal{O}(1)$ using simple single-qubit rotations $R_y(x_i)$. Amplitude embedding, while qubit-efficient ($\mathcal{O}(\log n)$ qubits), requires complex multi-controlled rotational decomposition that drastically inflates CNOT gate counts. For 4 qubits, angle embedding is physically robust, computationally fast on simulators, and resilient against hardware decoherence.
            

          


          

            
Q3: Did the system achieve "Quantum Advantage"?

            

              Answer: No, and claiming quantum advantage would be scientifically false. The VQC achieves 83.3% test accuracy on simulator, matching the classical RBF SVM (83.3%), while classical linear models achieved 87.9%. Quantum advantage requires solving a problem asymptotically faster or with provably higher accuracy than the best classical algorithms on quantum hardware with error mitigation. This capstone is an educational prototype exploring variational representations, not an empirical proof of quantum supremacy.
            

          


          

            
Q4: How do you mitigate the Barren Plateau problem during training?

            

              Answer: Barren plateaus occur when gradients vanish exponentially as circuit depth and qubit count increase ($Var[\partial_{\theta} \langle O \rangle] \in \mathcal{O}(2^{-n})$). We mitigate this by: (1) keeping qubit count small ($n=4$), (2) restricting variational ansatz depth to $L=2$ layers, (3) using local Pauli-Z measurement observables rather than global multi-qubit projections, and (4) initializing weights near zero ($0.05 \cdot \mathcal{N}(0, 1)$).
            

          


          

            
Q5: How does the Quantum Classifier support multi-disease finding detection?

            

              Answer: Rather than forcing a single mutually exclusive classification, thoracic imaging frequently features co-occurring findings (e.g. Infiltration and Effusion). We measure all 4 Pauli-Z expectation values simultaneously in a single circuit pass: $\mathbf{e} = [\langle Z_0 \rangle, \langle Z_1 \rangle, \langle Z_2 \rangle, \langle Z_3 \rangle]^T \in [-1, 1]^4$. A calibrated projection head $\mathbf{z} = \mathbf{W}_q \mathbf{e} + \mathbf{b}_q$ maps these quantum state correlations to independent finding logit scores $\sigma(z_k) \in [0, 1]$ across the 8 target pathologies.
